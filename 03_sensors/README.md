# 센서류 확장

이 폴더에는 다양한 센서 관련 MakeCode 확장이 포함됩니다.

## 포함된 센서

### 온도/습도 센서
- DHT11 - 온습도 센서
- DHT22 - 고정밀 온습도 센서
- DS18B20 - 방수 온도 센서
- LM35 - 아날로그 온도 센서
- SHT30 - 고정밀 온습도 센서 (I2C)

### 거리/초음파 센서
- HC-SR04 - 초음파 거리 센서
- VL53L0X - 레이저 거리 센서
- GP2Y0A21YK - 적외선 거리 센서
- US-100 - 초음파 거리 센서

### 조도/광 센서
- BH1750 - 디지털 조도 센서
- TEMT6000 - 아날로그 조도 센서
- TSL2561 - 고정밀 조도 센서
- APDS9960 - 색상/제스처 센서
- TCS34725 - RGB 색상 센서

### 가속도/자이로 센서
- MPU6050 - 6축 가속도/자이로
- ADXL345 - 3축 가속도 센서
- GY-521 - MPU6050 모듈

### 기압/고도 센서
- BMP280 - 기압/온도 센서
- BME280 - 기압/온도/습도 센서

### 가스/공기질 센서
- MQ-2 - 가연성 가스 센서
- MQ-135 - 공기질 센서
- CCS811 - CO2/VOC 센서
- SGP30 - 공기질 센서

### 기타 센서
- PIR - 적외선 인체감지
- Soil-Moisture - 토양 습도 센서
- Water-Level - 수위 센서
- Sound - 사운드 센서
- Vibration - 진동 센서
- Flame - 불꽃 센서
- Touch - 터치 센서
