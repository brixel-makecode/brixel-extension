# 디스플레이류 확장

이 폴더에는 다양한 디스플레이 관련 MakeCode 확장이 포함됩니다.

## 포함된 디스플레이

### LCD
- LCD1602-I2C - 16x2 문자 LCD (I2C)
- LCD2004-I2C - 20x4 문자 LCD (I2C)

### OLED
- SSD1306-128x64 - 0.96인치 OLED
- SSD1306-128x32 - 0.91인치 OLED
- SH1106 - 1.3인치 OLED

### LED
- WS2812B - 네오픽셀 LED 스트립
- TM1637 - 4자리 7세그먼트
- MAX7219 - 8x8 LED 매트릭스
- HT16K33 - LED 매트릭스 드라이버
- 74HC595 - 시프트 레지스터 LED

### TFT
- ST7735 - 1.8인치 TFT LCD
- ILI9341 - 2.4인치 TFT LCD
