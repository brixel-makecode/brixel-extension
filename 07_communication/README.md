# 통신 모듈류 확장

이 폴더에는 다양한 통신 모듈 관련 MakeCode 확장이 포함됩니다.

## 포함된 통신 모듈

### 무선 통신
- HC-05 - 블루투스 모듈
- HC-06 - 블루투스 슬레이브 모듈
- ESP8266 - WiFi 모듈
- ESP32 - WiFi/블루투스 모듈
- nRF24L01 - 2.4GHz 무선 모듈
- LoRa - LoRa 무선 모듈

### RFID/NFC
- MFRC522 - RFID 리더
- PN532 - NFC 모듈

### GPS
- NEO-6M - GPS 모듈
- NEO-7M - GPS 모듈

### 적외선
- IR-Receiver - 적외선 수신기
- IR-Transmitter - 적외선 송신기
