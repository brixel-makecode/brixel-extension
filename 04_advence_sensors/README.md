# 기타 확장

이 폴더에는 다양한 기타 모듈 관련 MakeCode 확장이 포함됩니다.

## 포함된 모듈

### 시간
- DS1302 - RTC 모듈
- DS3231 - 고정밀 RTC 모듈

### 입력
- Joystick - 조이스틱 모듈
- Keypad-4x4 - 4x4 키패드
- Keypad-4x3 - 4x3 키패드
- Rotary-Encoder - 로터리 엔코더
- Button - 버튼 모듈
- Potentiometer - 가변저항

### 저장
- SD-Card - SD 카드 모듈
- EEPROM - EEPROM 모듈

### 전원
- INA219 - 전류 센서
- ACS712 - 전류 센서
- Voltage-Sensor - 전압 센서

### 기타
- Laser - 레이저 모듈
- Reed-Switch - 리드 스위치
- Tilt-Sensor - 기울기 센서
